# Chimera C2 Framework

Advanced red team command and control framework with 300+ specialized agents, kernel-level modules, and AI-powered orchestration.

## Overview

Chimera is a modular offensive security platform for authorized penetration testing. It demonstrates full-spectrum attack chain capabilities from reconnaissance to exfiltration.

Key Features:
- 300+ specialized agents
- Kernel-level components (C)
- AI-integrated orchestration
- Human-in-the-Loop security

## Quick Start

1. Clone: git clone https://github.com/ninja1984/Chimera_C2.git
2. Install: pip install -r requirements.txt
3. Configure: cp config/.env.example config/.env
4. Run: source config/.env && python3 Orchestrator/autonomous_orchestrator.py

## Configuration

All IPs use environment variables. See config/.env.example.

## Security

Strictly for authorized security testing only. Lab environments only.
